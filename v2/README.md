# Azrienoch v2 -- from scratch

A second, independent build of Azrienoch, living entirely in this
directory. It shares nothing with the repository root's existing
pipeline (`tools/`, `sources/`, `fonts/`) -- no imported font, no
extracted outlines, no reused code. Nothing at the root was touched or
deleted to make room for this.

## Why a second pipeline

The root build derives its letterforms, spacing and kerning from Roboto
Flex (see the root `README.md`). This one doesn't derive from any
existing font at all: every glyph outline is generated by a parametric
drawing function in `tools/glyphset.py`, built from two primitives
(`tools/geometry.py`): a straight-sided polygon and a pair of concentric
ovals. There is no source font anywhere in this directory's dependency
graph.

## Design references

Three typefaces were named as the design brief's reference points --
none of their outline data touches this code:

- **Jost** (OFL) -- geometric sans construction discipline: forms built
  from circles, straight stems and simple joins, not from stroke
  contrast or historical letterforms.
- **Helvetica** -- proprietary (Linotype/Monotype); referenced only for
  its rational, flat/square-cut terminals and its directness (no
  ball terminals, no bracketed serifs, tight apertures). Inspiration
  only, per license: nothing traced or extracted.
- **Heliuum VAR** (205TF, Damien Gautier; commercial/trial license) --
  referenced for its underlying idea, not its shapes: a single font
  built as "a typographic system for mixing and matching," meant to
  spark creative multi-line, multi-weight compositions rather than
  serve one fixed voice. That idea is what `wght`/`wdth` in this module
  are for -- see "Design goal" below.

## Design goal

The brief: a font that makes it *easy* to find creative ways to fit text
together across multiple lines and multiple weights/widths -- lockups,
not just paragraphs. Two structural decisions serve that directly:

- **Vertical metrics are fixed across the entire `wght` range**
  (`tools/params.py`: cap-height 700, x-height 500, baseline 0, same at
  every weight). A Thin line and a Black line share the same baseline
  and x-height, so mixed-weight lines stack and align without
  compensating for a shifting cap-height -- the opposite choice from the
  root pipeline, which deliberately ties height to weight.
- **Flat, square terminals everywhere, no optical stroke contrast.**
  Every stroke is a straight-sided or constant-radius shape; nothing
  tapers. That's what makes heavyweight and lightweight instances of the
  same letter still read as the same skeleton at a glance, which is what
  makes swapping weights mid-line (rather than committing to one weight
  per composition) actually work visually.

## Axes (current)

| Axis | Tag | Range | Default |
|---|---|---|---|
| Weight | `wght` | 100-900 | 400 |
| Width | `wdth` | 75-100 | 100 |

Masters: the full `wght` x `wdth` grid (`tools/params.py::MASTER_GRID`),
3 weight samples (100/400/900, so `wght` gets a bend rather than one
straight interpolation) x 2 width samples = 6 masters. The default
location (400, 100) is itself one of the six, as a designspace requires.

## Status: proof-of-concept skeleton, not a usable font yet

This is deliberately the first step, scoped down to prove the
architecture compiles and interpolates cleanly before drawing a full
character set:

- **8 glyphs only** -- `H O o n v T l one` -- chosen to cover the four
  stroke situations every other letter reuses: a straight stem (H, T,
  l), a full round bowl (O, o), a stem-to-curve arch spring (n), and a
  diagonal join (v).
- **No kerning yet.** The brief calls for kerning "fine-tuned for all
  possible combinations" -- that needs a real glyph set to tune pairs
  against, so it's deferred rather than half-done against 8 letters.
- **No hand-eyeballed optical correction yet** (overshoot on round
  letters past the cap-height/baseline, optical sizing between stem and
  bowl weight, etc.) -- next pass, once more letters exist to compare
  against.

Verified so far: `python3 -m v2.tools.designspace_build` compiles a
variable TTF with both axes interpolating correctly (`fvar`/`gvar`
round-trip checked directly, and `tools/preview.py` renders the proof
set at four corners of the axis space through the compiled font's real
`glyf`/`gvar` data -- not a re-derivation of the drawing functions --
confirming no self-intersections or broken topology across the grid).

## Building

From the repository root:

```
pip install fontTools ufoLib2 fontmake
python3 -m v2.tools.designspace_build
```

Output: `v2/sources/*.ufo`, `v2/sources/AzrienochV2.designspace`,
`v2/fonts/variable/AzrienochV2-VF.ttf`.

Visual QA (renders the proof set at four axis locations to a PNG, from
the compiled font's own outlines): `python3 -m v2.tools.preview out.png`
(needs `matplotlib`, dev-only, not part of the build).

## Layout

```
v2/tools/geometry.py           polygon + concentric-oval primitives
v2/tools/glyphset.py           per-glyph parametric drawing functions
v2/tools/params.py             axis model, master grid, vertical metrics
v2/tools/ufo_build.py          builds one UFO per master from glyphset.py
v2/tools/designspace_build.py  writes the designspace, runs fontmake
v2/tools/preview.py            dev-only visual QA render
v2/sources/                    build output (UFOs + designspace)
v2/fonts/variable/             build output (compiled variable TTF)
```

## Next steps

1. Extend `glyphset.py` to the rest of uppercase, lowercase and digits,
   reusing the same four stroke constructions.
2. Add overshoot/optical correction once enough round + flat letters
   exist to compare against each other.
3. Kerning: derive pair classes from the full glyph set and tune by eye
   against rendered specimens, not formula-only spacing.
4. Revisit whether a third axis belongs here for the Heliuum-style
   "mix and match" goal specifically (e.g. something that shifts how
   caps sit relative to the baseline for stacked lockups), once the
   base letterforms are settled enough to know if `wght`/`wdth` alone
   already deliver on it.
