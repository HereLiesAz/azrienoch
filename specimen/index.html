05 — Correction Log
Marked against the previous proof.
Named instances
The compiled variable font interpolated its full range correctly but exposed only Regular to any style picker — no fvar instances, no STAT table. All 12 master locations are now named instances with a proper STAT axis-value label per stop.
Condensed weight
The wdth axis thinned every stem by the same flat factor it narrowed a counter by — an obvious squish at Black/Condensed. Replaced with an ink-density weighted compression that leaves stems close to full width and pushes the narrowing into counters and sidebearings instead.
Kerning
None existed. 533 pairs now extracted directly from Jost's own kerning table, scaled by width, with a correctly inheriting d's kerning rather than a borrowed shape it no longer has.
c / e roundness
Per-point Cartesian interpolation between Arimo's Regular and Bold warped both letters into an asymmetric, pear-shaped outline at Black, and folded them into self-intersecting knots at Thin. Replaced with polar interpolation (radius + angle from a shared centroid), which keeps every point's motion radial — round at any extrapolation, in either direction.
Kerning — O/Y
Jost's own donor value for O-Y read visibly looser than T-O in "TOY" — matching it by the closest-approach silhouette distance still looked loose by eye, so it was pushed further by direct visual judgment: O-Y now sits at −100 (Jost's own donor value was −30).
c / e vs o
c/e no longer come from a separate donor font at all -- they're built directly from this project's own o (a cut-open ring, plus a crossbar for e), so their bowl/counter proportions match o's by construction at every weight and width, not by width-matching after the fact (two earlier attempts at that were reverted). One known residual: at the single most extreme corner of the design space (Thin + Condensed together), e's aperture terminal folds into a tiny self-intersecting spike.
Character set
Grew from 62 glyphs (basic Latin + digits) to 338 -- punctuation, Latin-1 Supplement, Latin Extended-A, and Cyrillic added, matching the repository root's own v1 pipeline except Greek (Jost itself barely has any). New glyphs render with Jost's own raw shape but aren't yet kerned or given the same terminal-cut/round-counter treatment as the original 62.
B / digit 4 self-intersections
Both flagged by an earlier geometric self-intersection sweep as real defects; direct rendering at every weight/width shows neither actually draws with a visible artifact -- a harmless retrace under nonzero-winding fill in both cases. Confirmed, not assumed: no fix needed.
GRAD axis
A fourth axis, matching v1's own range (-50 to 50). Jost has no native grade axis to draw from (unlike v1's donor, Roboto Flex, which does) -- approximated instead by sampling Jost's own outline at a nearby wght for shape while keeping the advance width from the requested wght itself, so text reads bolder/lighter without reflowing a layout. Confirmed: width is bit-for-bit identical across GRAD at a given wght/wdth while the ink visibly thickens/thins.
Accented c/e/s re-spliced
18 accented letters whose base is c/e/s (ç èéêë ćĉċč ēĕėęě śŝşš) now carry THIS project's own c/e/s shape with Jost's own diacritic mark re-attached, instead of Jost's native c/e/s -- without this they'd read as a different, inconsistent letterform sitting next to this project's own modified c/e/s in the same word.
Kerning coverage
Grew from 533 pairs (the original 62 ASCII letters/digits) to 7,774 -- covers this project's full character set (Latin-1, Latin Extended-A, Cyrillic) now, not just ASCII. Jost's own kerning table already had pairs for all of these scripts, so this only needed the existing donor-kerning extraction pointed at the wider glyph set, not new extraction logic.
Accented-letter serif/counter classification
Accented Latin letters (ē ō ń etc.) used to get Jost's raw shape with none of this project's own per-letter-class refinement -- ā's counter wasn't forced to match o's the way a's is, and accented letters fell through to a generic baseline-only serif-foot rule regardless of their base letter's actual class. Now resolved via Unicode NFD decomposition (ń → n) before classification, so an accented letter gets exactly its base letter's treatment. Caught a real bug doing this: accented n was keeping a spurious second foot that plain n's own single-story rule (exactly two feet) already correctly drops. Cyrillic has no Latin base to resolve to and is still untouched.
Cyrillic serif/counter classification
Nine lowercase Cyrillic letters (а е э о с м р у х) confirmed by direct rendering to share a plain Latin letter's structural class (o/c/e/m/p/y/x) now get that letter's serif-foot and round-counter treatment -- р's bowl reshapes to match o's, у gets y's two-foot rule, etc. The other ~23 Cyrillic lowercase letters (bridge/ladder shapes like н/п, which read as a lowercase Latin "H" rather than "n") have no clean analog and were deliberately left on the generic default, which is already the correct treatment for them.
Greek added
69 Greek characters, sourced from the repository root's own vendored Roboto Flex (Jost has almost no Greek -- 4 codepoints total) via a new roboto_flex_source.py that reuses v1's own already-tuned weight/width-to-axis mapping wholesale, read-only. 408 glyphs total now; the full 36-master grid compiles with consistent point topology, and Greek was rendered and checked at several master combinations (including Black+Condensed+Slab) with no defects. It carries none of this project's own quirks/serifs per-letter-class refinement or kerning yet -- Roboto Flex's outlines don't share Jost's point topology for the structural-match approach those rely on to find anything.
Serif foot sizing fixed at every weight
Feet were sized off the wght=400 reference instance's own proportions rescaled by each master's overall advance width -- wrong, since stem thickness shrinks with wght far faster than advance width does. At Thin this made feet sit wider than the real stem, poking out on both sides even at SERF=0. Fixed by measuring each master's own actual stem width directly, and hard-capping foot height at that real width -- at every weight, not just Black: a foot must never equal or exceed the stroke it grows from. Confirmed at Thin, Regular, Black, and Thin+Condensed.
Serif flare halved; proof display bug fixed
The "A's right serif looks way longer than the left" report traced to two things: A's feet are actually mirror-symmetric (confirmed by measuring the compiled font's own points and a real browser render), but this proof's own instance-sample cards were clipping the left side (overflow: hidden, no left margin) -- a heavy diagonal letter's negative left sidebearing got cut off on one side but not the other, making the unclipped side look twice as long. Once seen in full, that length was itself too prominent, so every letter's serif flare was halved globally. This page's own clipping is also fixed (overflow: visible + left margin) so it won't mislead the next comparison.
Serif flare cut to 2/3; foot height tightened at thin weights
Two more rounds of direct comparison: flare cut again to 2/3 of the already-halved length (down to 1/3 of the original), and foot height re-tuned specifically for thin weights -- capping at the full stem width still let a thin stroke's foot reach half its own thickness, reading as a chunky block rather than a delicate nub. Height's cap is now 40% of the measured stem width. Confirmed via real browser render: Thin's feet are now a small, proportioned nub; Black's remain clearly legible.
Serif foot height brought back up
The previous height tightening overcorrected -- called too short immediately after. Flare length was fine and untouched; height's coefficient moved to 0.35 (was 0.42, then 0.28) and its cap to 60% of the measured stem width (was 100%, then 40%), landing between the original too-tall setting and the too-short one right after it.
Fixed serif height vanishing at Thin (rendering-scale bug)
Black/widest was already perfect, but Thin still looked like only width had grown, not height. Root cause: a height purely proportional to a Thin stem's own small width rounds to a handful of units out of a 1000-unit em -- sub-pixel at any normal display size -- while the width flare survives antialiasing because it has more on-screen pixels. Added an absolute floor on foot height so it stays visible on the thinnest stems, confirmed via a pixel-exact font-unit-scale crop and a normal browser render side by side. Black/wide unaffected -- the floor sits well under what the proportional formula already produces there.
Reverted wrong fix; corrected the actual Thin/Black disproportion
The previous "make height visible" floor was backwards -- it increased Thin's height toward its own full stem width when the repeated direction was to decrease it. Reverted. The real cause: a flat +1 unit bonus added on top of the proportional term is negligible against Black's thick stem but ~17% of Thin's thin one, computed directly -- Black's foot came out to 35.5% of its own stem width, Thin's to 42.1%. Fixed by interpolating from hairline straight to the fully-proportional target instead of always adding the hairline as a bonus: both extremes now land on the identical 35% ratio.
c / e rebuilt
e had no visible crossbar and a broken aperture at every weight: its terminals were cut at fixed angles, then rotated flat through hardcoded point indices that no longer matched the contour. Both letters are now built from o's ring with every terminal exactly horizontal by construction. c's upper terminal sits level with the top of e's crossbar, where e's bowl stops curving; its lower terminal sits level with e's. The Thin Condensed self-intersecting spike is gone: there's no self-intersection at any of the 36 masters. Known consequence: at Black, e's aperture narrows to a slit.
V / W / M / v / w stroke widths
Jost's Futura-style contrast (thinner inner diagonals on W/w, diagonals mismatched with stems on M), made worse by the slope-dependent effect of condensing, is replaced by one perpendicular thickness per glyph, at every master. Outer silhouette, advance width and kerning are unchanged. Strokes are measured between each stroke's own parallel sides. M now overshoots like every other pointed letter: its middle vertex drops below the baseline to V's own vertex depth, with each diagonal re-solved between its apex and that vertex.
S terminals
Jost cuts both S terminals on the diagonal; s was already horizontal. Both S terminals are now cut horizontal like s, at every master. Terminals are kept inside the bowl, so neither overhangs it.
Thin Condensed serifs
Thin Condensed stems (~8 units) fell under the 10-unit stem-detection floor when each master's own stem was measured. Every foot then took a fallback width several times the stem's and landed off-center, which is why they read as blobs. Measurement now uses a 1-unit floor, so Thin Condensed feet match Thin's proportions.
